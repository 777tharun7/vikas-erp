1. 🎓 **Admissions & Lead Engine:** Inquiry funnel, entrance test scores (`92/100`), verification status, and 1-click **Enroll Student** action.
2. 🎓 **Student Roster 360° & Bulk Promotion:** 832 Students directory filterable by Class & Section (`Class I` to `Class X B`), UDISE PEN IDs, parent contacts, and 1-click **Annual Bulk Promotion** workflow.
3. 📚 **Academics & BSE Telangana Curriculum:** Telangana Board syllabus progress tracking (*Class X Math 82%, Class X Physics 78%*), chapter completion, and syllabus PDF download.
4. 📝 **Exams & Marksheet Generator:** Grade calculators, GPAs, and official report card generation.
5. 🕐 **Attendance & Dual Leave Engine:** Period-wise student attendance & student leave request approval portal for teachers.
6. 💰 **Fee Collection Ledger:** Q2 Fee collection ledger (INR `₹14.25 L`), installment tracking (Term 1, Term 2, Term 3), defaulters list, and automated SMS reminders.

9. 📚 **School Library & Book Catalog:** 2,450 Books catalog, shelf locations (`Shelf M-04`), book issue/return ledger.
